# 界面截图

| 文件名 | 内容 |
| :--- | :--- |
| `gui.png` | 主界面（默认 940×660）：左列硬件控制、右列状态 + 传感器 |
| `gui-resized.png` | 把窗口拉大到 1250×860 后：传感器全部数据一屏可见 |

说明：这两张是在**非管理员**会话下截的，所以左侧 MIFS 控件（性能模式/风扇/硬件开关/背光）
显示为「未实现」灰色 —— 那是权限降级路径，不是布局问题；右侧传感器数据是真实的
（PDH + WMI 不需要管理员）。

想替换成你自己的截图：用 `Win + Shift + S` 截窗口，覆盖同名文件即可。
注意别把序列号、用户名等个人信息截进去。
