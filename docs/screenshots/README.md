# 界面截图

把截图放进这个目录，README 顶部的界面预览就会显示。

| 文件名 | 内容 |
| :--- | :--- |
| `gui.png` | 主界面（性能模式 / 风扇 / 启动与 OSD 区域都要露出来） |
| `tray.png` | 托盘图标 + 展开的右键菜单（可选） |
| `osd.png` | 自带屏幕提示弹出时的样子（可选） |

建议：

- 用 `Win + Shift + S` 截窗口区域，直接存 PNG
- 主界面窗口约 480×670，不需要缩放
- 截图里不要包含序列号、用户名等个人信息（窗口标题栏只显示程序名，一般没问题）

截好后在 `README.md` 里取消这一段注释即可：

```markdown
![OpenMIFS 主界面](docs/screenshots/gui.png)
```
