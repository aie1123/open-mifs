### 能力矩阵

| 功能号 | 功能 | 结果 | 备注 |
| :---: | :--- | :---: | :--- |
| 8 | 性能模式 | ✅ | 可读可写。取值编码与上游驱动相反 |
| 9 | GPU 模式 | ❌ | `常规故障` —— 本机无独显 |
| 10 | 键盘类型 | ✅ | 恒返回 `00` |
| 11 | Fn 锁 | ✅ | 可读可写 |
| 12 | 触控板锁 | ✅ | 可读可写 |
| 13 | 风扇转速 | ✅ | 双风扇，实测 ~2500 RPM |
| 16 | RGB 模式 | ❌ | `常规故障` —— 本机白光键盘 |
| 17 | RGB 颜色 | ❌ | `常规故障` |
| 18 | 键盘背光亮度 | ✅ | 可读可写 |
| 19 | 供电状态 | ✅ | `1` 外接电源 / `0` 电池 |
| 20 | 风扇满速开关 | ⚠️ | 调用成功，但写入被忽略（写前写后读回值不变） |
| 21 | 风扇满速值 | ⚠️ | 恒返回 `00` |
| 22 | CPU 温度 | ❌ | 调用成功但数据恒为 0 |
| 23 | CPU 功率 | ❌ | 调用成功但数据恒为 0 |

**可用 9 个 / 未实现 5 个。**

### 性能模式取值实测

| 值 | 含义（本机实测） |
| :---: | :--- |
| 0 | 性能 |
| 1 | 均衡 |
| 2 | 低功耗（BIOS 默认） |
| 3 | 满速（未验证） |

> ⚠️ 上游 Linux 驱动 `tongfang-mifs-wmi` 标注为 `0=均衡 1=性能 2=低功耗`，与本机相反。
> 换机型请务必用 `.\src\mifs.ps1 bench` 实测校正。

### 本机没有的能力

- **电池充电阈值**：MIFS 功能号里没有，`scan 0..63` 也没扫出来
- **风扇转速调节**：`13` 号只读，调速需要直接写 EC RAM（MIFS 不暴露）
- **CPU 温度**：本机未实现，需要 HWiNFO 之类的工具

## 如何贡献你的机型

跑这三条，把输出贴进 issue：

```powershell
.\mifs.cmd probe
.\mifs.cmd test
.\mifs.cmd scan 63
```

再附上机型信息：

```powershell
Get-ItemProperty 'HKLM:\HARDWARE\DESCRIPTION\System\BIOS' |
  Select-Object SystemProductName, BIOSVersion, BIOSReleaseDate, BaseBoardProduct
Get-CimInstance Win32_Processor | Select-Object Name
```

建议一并说明：

- 有没有装官方控制中心（有没有、哪个版本）
- 各档性能模式的主观感受（噪音、发热、跑分）
- 任何「调用成功但功能没反应」的情况
