## 0. Brief（v2：以"机器健康、提权运行"为主场景）

| 问题 | 回答 |
| :--- | :--- |
| 这是什么 | 一台**具体笔记本**（机械革命无界 14 Pro / 同方 MIFS）的硬件控制台 |
| 使用者是谁 | 机器主人：懂硬件的折腾型用户，中文，认 ℃ / W / GHz / RPM / MT/s |

### 1.2 状态词表（**v2 新增，为满足 `ui-ux-pro-max` P1「Color Only」规则**）

该技能规则原文：*"Don't convey information by color alone — use icons/text in addition to color"*，
**严重度 High**。所以每个状态都走 **颜色 + 文字/符号** 两个通道：

| 状态 | 颜色 | 文字/符号（必须同时出现） |
| :--- | :--- | :--- |
| 正常 | 绿 | 无标记（默认态不标注） |
| 偏热 | 琥珀 | 数值后跟档位字：`55 ℃ 温` |
| 热 | 橙 | `78 ℃ 热` |
| 烫 | 红 | `92 ℃ 烫` |
| 受限 | 琥珀 | `（Type-C 供电下禁用）` |
| 不可用 | `Muted` | `不可用` + ToolTip 给原因 |
| 异常 | 红 | `⚠ 读取失败` |

> 托盘图标受 2~3 字符限制，档位并入 ToolTip（现状保留）；面板上用完整档位字兜底。

### 1.3 字体与字号

| 角色 | 字体 | 字号 | 颜色 | 理由 |
| :--- | :--- | :--- | :--- | :--- |
| **关键读数值** | `Consolas` | **17pt Bold** | 按档位 | 首屏三大项（温度 / 功耗 / 风扇），等宽防抖动 |
| 普通读数值 | `Consolas` | 11pt Bold | `Ink` / 按档位 | 明细行，小数点成列 |
| 单位 | `Microsoft YaHei UI` | 8pt | `Label` | 紧贴数值右 4px（**不用 Muted**，单位承载信息） |
| 标签 | `Microsoft YaHei UI` | 8pt | `Label` | 右对齐固定 92px 列 |
| 区块标题 | `Microsoft YaHei UI` | 9pt Semibold | `Ink` | 句子式；**不全大写、不加眉标、不编号** |
| 正文/按钮 | `Microsoft YaHei UI` | 9pt | `Ink` | |

### 1.4 间距 / 圆角 / 表面语义

- 间距刻度 `4 / 8 / 12 / 16 / 24 / 32`；控件内边距 8；同组间距 8；**组间 24**
- 读数行高 **24**（技能规则 `Line Height` 1.5~1.75：24px ÷ 11pt ≈ 1.5 ✓）；控件行高 28
- 圆角：**只读面板 0（方角 + 1px 内线）/ 可交互控件 4**
- **表面语义**：凹陷方角 = 只读；平面圆角 = 可操作 —— 用它替代"7 个同款 GroupBox"

## 2. 布局 v2（结构性改动：取消"状态"镜像面板）

### 2.1 核心决定

v0.5.6 右列「状态」共 10 行，其中 **7 行是左列控件的回读镜像**：

| 状态面板行 | 与谁重复 |
| :--- | :--- |
| 性能模式 均衡 | 左列单选按钮 |
| 风扇1 / 风扇2 | 左列风扇标签 **且** 传感器面板（**且数值还不一致**，见 N1） |
| 风扇满速 被电源类型禁用 | 左列禁用按钮 |
| Fn 锁 / 触控板锁 / 键盘背光 | 左列复选框 / 按钮 |

**真信息只剩 3 行**：供电类型、OSD 状态、开机自启。
→ **v2 取消独立"状态"面板**：回读并入控件本身（控件下方一行 8pt 状态字），
环境三项（供电 / OSD / 开机自启）合并到读数面板底部一行。
`ui-ux-pro-max` 的 `Redundant Entry`（WCAG 2.2 A：同一信息不应在同一流程出现两次）支持这个判断。

### 2.2 线框

```
┌────────────────────────────────────────────────────────────────────────────┐
│ OpenMIFS        均衡 · 外接电源 · OSD 正常              15:17:27   [刷新]   │ 40px
├──────────────────────────────┬─────────────────────────────────────────────┤
│ 控制（平面 · 左 456 固定）     │ 读数（凹陷 · 方角 · 自适应）                 │
│                              │ ┌ 关键三项 ───────────────────────────────┐ │
│ 性能模式                      │ │   55 ℃        23.96 W        3075 RPM   │ │
│ ┌────────┬────────┬────────┐ │ │   温度 温       功耗           风扇      │ │
│ │ 低功耗 │●均衡   │ 性能   │ │ └─────────────────────────────────────────┘ │
│ └────────┴────────┴────────┘ │ ┌ 明细 ───────────────────────────────────┐ │
│  已生效                       │ │ 频率   3.96 GHz     负载      24.9 %    │ │
│                              │ │ GPU    49 ℃         显存     372 MB     │ │
│ 硬件开关                      │ │ 内存   11.9 / 31.2 GB                   │ │
│  [ ] Fn 锁     [x] 触控板锁    │ │ 磁盘   31 ℃   SSD 954 GB               │ │
│  键盘背光  [0][1][2][3]        │ │ 电池   92 %（健康 100 %）                │ │
│                              │ └─────────────────────────────────────────┘ │
│ OSD 与启动                    │  外接电源 · OSD 正常 · 开机自启 开            │
│  [重启][诊断][打开目录]        │                                             │
│  [x] 开机自启（静默进托盘）    │  可用 16 项                    ▸ 偏好设置     │
└──────────────────────────────┴─────────────────────────────────────────────┘
```

**对齐规则**
- 左列：控件左缘对齐同一条线（x=12）；标题同左缘
- 右列：标签右对齐 92px → 数值**右对齐**（等宽字体保证小数点成列）→ 单位左对齐 4px
- 关键三项：三列等宽、数值居中、下方小字标签（仪器表盘的"三大表"）

## 3. 设计原则（v2 · 6 条）

1. **数值是主角**：关键三项 17pt 等宽、明细 11pt 等宽；标签/单位退到 8pt 灰。
2. **一遍不重复（No Mirror）**：同一事实只出现一处；控件回读贴在控件上，不做镜像面板。
3. **凹陷 = 只读，平面 = 可操作**：表面形态编码交互性。
4. **一套语义色跨端守恒**，且**永不只靠颜色**（§1.2 状态词表）。
5. **一处大胆，其余克制**：唯一的"重"元素是「关键三项」大数字，其次是模式拨杆。
6. **文案即界面**：动作名 = 结果名（"重启 OSD" → "OSD 已重启"）；0 值不显示；一次性说明不常驻。

### 4.2 `ui-ux-pro-max`：实跑检索到的规则与其落法

| 规则 | 严重度 | 我们的落法 |
| :--- | :--- | :--- |
| `Color Only` — Don't convey information by color alone | **High** | §1.2 状态词表（颜色 + 档位字） |
| `Focus States` — 可见焦点指示 | **High** | `Ring` 2px 外框 |
| `Keyboard Navigation` — Tab 顺序与视觉顺序一致 | **High** | 定义 `TabIndex`：左列自上而下 → 读数区 → 刷新 |

| P6「Raw hex in components」 | — | 23 处 `Color.FromArgb` 收敛到 §1.1 常量表 |
| P8「Progressive disclosure」 | — | 未实现项折叠；偏好设置折叠 |

## 7. 验收标准（可测）

1. **3 秒判据**：遮住标题只看内容，3 秒内能回答"模式 / 温度 / 功耗 / 风扇" —— 四项都在首屏且字号最大
2. **无重复**：同一事实在界面出现次数 = 1（风扇 RPM、模式、锁状态）
3. **列对齐**：`9 %` / `24.9 %` / `105.5 W` 三个值的小数点落在同一条竖线
4. **不只靠颜色**：转成灰度截图后，温度档位仍可判读（因为有档位字）
5. **对比度**：标签 ≥4.5:1（实测 5.28 / 4.84 ✓）；`Muted` 只出现在禁用与未实现
6. **键盘**：Tab 可走完所有可交互控件，且有可见焦点环
7. **零截断**：任何一行文本都不出现 `…`（ToolTip 除外）
